# Levantar el servidor:

1. Instalar dependencias:
   npm install

# Levantar el ORM:

1. npx prisma

# Actualizar el esquema de la base de datos:

1. npx prisma db pull

# Levantar el servidor de prisma:

1. npx prisma studio (opcional, solo para tener la db local)

# Levantar la app

1. npm run dev
